The Economist-style section line that opens editorial articles and cards — red section word, pipe, grey sub-rubric. Use inside `[data-theme="editorial"]`.

```jsx
<Rubric section="Insights" sub="The realfast view" href="/blog" />
```

Category → sub defaults: Insights → "The realfast view", Agentforce → "On Agentforce", realfast labs → "From the Labs", Stories → "Field notes".

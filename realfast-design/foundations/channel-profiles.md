# Channel profiles and rule precedence

The core is the light editorial language. A channel profile changes only the rules listed here. Read this table before the channel's detailed guide; it resolves older contradictory wording. Functional accessibility requirements apply in every channel.

| Decision | Editorial / documents | Marketing website | Social | Video |
|---|---|---|---|---|
| Ground | White and cream | White/cream with scoped dark bands | Light opening, alternating paper, one dark close | Light opening, one dark close |
| Corners | 2px; rubric pills only | Pill CTAs; content-card recipes in website guide | 2px | 2px; rubric pills only |
| Glow | None | Published dark-band and CTA-hover recipes only | Published subtle opening wash and dark closing recipe only | Published dark closing recipe only |
| Gradient words | None | 1–2 accent words on dark bands only | Follow social guide | Follow video guide |
| Section rules | Hairlines allowed | No rules separating full-bleed sections | Content rules only | Content rules only |
| Motion | Shared component behavior | Website entrances; reduced-motion alternative | Static export | Video beat and timing rules |

No other halo, gradient, pill, or animated effect is implied by these exceptions. Detector findings for the named recipes are reviewed as intentional choices, not hidden or reported as absent. Cream paper, serif display, and functional editorial rubrics remain deliberate brand choices.

The name is lowercase and italic in styled prose. Plain text, code identifiers, URLs and the supplied logo asset do not require literal italic markup. Use US spelling and spaced hyphens in new marketing copy; preserve quotations and existing source facts.

The muted illustration palette is supplied for use, but its approval status remains pending confirmation from the brand owner. Do not describe that approval as complete. Existing assets are preserved.

Use `--text-accent` for small red text on white or cream. Use `--accent` for red fills and graphic accents, with white text only on approved solid fills. `--rf-red` is the canonical #E3120B; `--rf-red-400` remains #F7394D. Text links use the accessible editorial blue alias; blue buttons use canonical brand blue.

## Review questions

A finished piece must answer **no** to “Could this belong to any company with the logo swapped?” and **yes** to “Does each accent carry meaning?” and “Does the copy say something specific and supported?”

UsageCharts sit on a light ground, never a dark band. The ramp is drawn straight from the Illustration Palette (see Colors › Illustration Palette, the --rf-illus-* tokens) so charts read in the same visual language as the spot art. For ordered or pipeline data use the value ramp --rf-illus-pale-blue › --rf-illus-dusty-blue › --rf-illus-slate-navy, reserving --success for the terminal "done / positive" series so the outcome reads at a glance. Set totals above each bar in --font-sans; keep axis labels and the legend in --rf-ed-muted. Avoid the raw illustration mid-tones side by side (grey / violet / blue) — they muddy; a single-hue light-to-dark ramp keeps multiple series legible. Never use the signal red as a data series; it stays a rare focal spark.

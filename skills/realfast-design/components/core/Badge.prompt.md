A compact pill label for categories, platform tags (ExoCode/ExoWork/ExoCortex), and statuses.

```jsx
<Badge tone="blue">ExoWork</Badge>
<Badge tone="red" outline>Insights</Badge>
<Badge tone="success">Live</Badge>
```

Tones: `neutral`, `blue`, `navy`, `red`, `ink`, `success`. Set `outline` for a hairline-only chip.
